# Deployment workflows

These website-only workflows connect the repository's focused API guides into complete deployment
routes. They remain outside the generated Agent Skills and snippet-verification corpus because they
combine third-party tools, hosted services, and platform-specific release operations.

## Available workflows

### [Remote GPU training to an iOS app](remote-training-to-ios.md)

Fine-tune Qwen3 on hosted NVIDIA hardware, preserve a reproducible Hugging Face checkpoint, and
derive separately versioned MLX Swift and Core AI artifacts for iOS.
